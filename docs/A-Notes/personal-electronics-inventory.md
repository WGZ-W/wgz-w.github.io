# 计划购入清单

## “买上一代（Buy Last-Gen）”或“旗舰降级”
- 显示器要求 4K，刷新率最低 120Hz
- 手机，安卓存储至少 512G；Apple 可以买 256G
- 电脑，Apple 最好是 24G + 515G；游戏本可以是 16G + 512G；如果有买电脑的强烈需求，直接买好的就可以，可以买Pro，但是现在不需要，尽量少看。

## 目前需要关注
- 4K 显示器
- 人体工学椅
- 显示器支架


## 未来关注
- 相机
- 镜头
- 电脑
