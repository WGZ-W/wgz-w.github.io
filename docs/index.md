### 早上起床仪式
- 先按摩按摩头部和身体
- 喝一杯温开水
- 洗漱；上厕所
- 去晒太阳；简单拉伸一下

### 晚上睡觉仪式
- 关闭大灯，开台灯。
- 睡前一小时不看发光屏幕，要看就看纸质书或墨水屏；阅读一本纸质书。
- 到点就睡，不为游戏、短视频、色情内容熬夜。

## 习惯

- 早睡早起，**23:00 - 7:00**；每晚睡 7 小时左右，**作息固定**；
- 固定起床时间，周末也一样；
- 每晚睡够 7 到 8 小时，别把 6 小时当作够用。
- 慢慢起床，拉开窗帘，喝一杯水，洗脸，上厕所，**去操场晒五到十分钟太阳**，吃早饭，吃两个鸡蛋，喝牛奶/豆浆。
- 在工位的时候要**有效率**；读文献；写代码。
- 一次只做一件事，不要边开会边回消息。
- 下午困了就睡 10 分钟，不要睡半小时。
- 别连着坐太久，隔一阵起身动一动。
- 每周打三次球拍类运动，每次 45 分钟。
- 不喝含糖饮料，换成无糖的也不算解决。
- 干活的时候要屏蔽其他的消息，专心干活，累了就休息，***先做两分钟***
- 多吃蔬菜，少吃零食，减肥。
- 中午午休半小时，起床后用洗面奶洗一下。
- 要休息好，也要吃好喝好，才可以健身。
- 多读书；买点纸质书，有些书其实就是一杯奶茶的价格。
- 收拾房间，收拾自己。
- 晚上不要打游戏，平常打游戏时间不要很长，最多两个小时，不要一直坐着。
- 不能集中精力的时候，就去散散步，带着耳机听听音乐，**走路不要看手机**。
- 养成微小的习惯（不需要用意志力去让自己行动）
  - 两分钟法则，做一件事，先做它的两分钟版本。
  - 阅读 Harry Potter 两页。
  - 健身，一个俯卧撑。
- Never Miss Twice in a Row （千万不要连续两天放弃）

### 如果不知道该如何改变，那么先从下面的小习惯做起
- 早睡早起
- 吃早饭
- 写下一天要做的三件事
- 健身，运动
- 阅读

### 如何自己创建和管理一个项目（）
项目流
```
Create repo (code and docs)
-> ssh origin remote 
-> link codex/claude code
```
> 每个项目都要有一个 Git 仓库，每次修改都记录好。
