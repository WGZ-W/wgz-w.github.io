## 健康作息时间表 & 习惯


|时间|事件|备注|
|-|-|-|
|7:00 - 7:30|起床洗漱，拉伸|
|7:30 - 8:30|吃饭，回一些 APP 消息，饭后读两页Harry Potter|
|8:30 - 11:30/12:00|上课/上班|

### Note：

- 早睡早起，**23:00 - 7:00**；固定睡觉 & 起床时间。
- 慢慢起床，拉开窗帘，喝一杯水，洗脸，上厕所，去操场晒晒太阳，吃早饭，吃两个鸡蛋，喝牛奶/豆浆。
- 在工位的时候要**有效率**；读文献；写代码。
- 多吃蔬菜，少吃零食，减肥。
- 中午午休半小时，起床后用洗面奶洗一下。
- 要休息好，也要吃好喝好，才可以健身。
- 多读书；买点纸质书，有些书其实就是一杯奶茶的价格。
- 收拾房间，收拾自己。
- 晚上不要打游戏，平常打游戏时间不要很长，最多两个小时，不要一直坐着。
- 不能集中精力的时候，就去散散步，带着耳机听听音乐，**走路不要看手机**。
- 养成微小的习惯（不需要用意志力去让自己行动）
  - 两分钟法则，做一件事，先做它的两分钟版本。
  - 阅读 Harry Potter 两页。
  - 健身，一个俯卧撑。
- Never Miss Twice in a Row （千万不要连续两天放弃）

### 如果不知道该如何改变，那么先从下面的小习惯做起
- 早睡早起
- 吃早饭
- 写下一天要做的三件事

### 如何自己创建和管理一个项目（）
项目流
```
Create repo (code and docs)
-> ssh origin remote 
-> link codex/claude code
```
> 每个项目都要有一个 Git 仓库，每次修改都记录好。


### Codex Remote
使用 ***SSH 反向隧道*** 在服务器上用 Codex ；
具体使用方法问 ChatGPT


### Note: 
- 当程序在一台机器上跑的很慢的时候，先检查**代码**的问题，如果代码没有什么问题，则有条件的话，可以去另一台机器上试试，很有可能是**机器的问题**。（都是实践出来的）。
- 实验室有条件就好好利用，比如有网线就直接插上用，别觉得麻烦。
